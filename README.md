Doctor Appointment System (PHP + MongoDB)
The Doctor Appointment System is a web-based application developed using PHP as the backend language and MongoDB as the NoSQL database. It allows patients to book appointments with doctors, view doctor profiles, and manage their bookings, while doctors and admins can manage schedules, appointments, and patient records.

Key Features:
Patient Registration/Login: Secure patient account creation and login.

Doctor Profiles: View doctors by specialty, availability, and ratings.

Appointment Booking: Patients can select date/time slots and confirm appointments.

Doctor Dashboard: Manage availability, view appointments, and update status.

Admin Panel: Manage users, doctors, appointments, and system reports.

MongoDB Integration: Stores data in flexible JSON-like documents, allowing fast and scalable performance.

Search & Filter: Quickly find doctors by name, specialty, or location.

Technology Stack:
Frontend: HTML, CSS, JavaScript (optional: Bootstrap or any UI framework)

Backend: PHP

Database: MongoDB (used to store users, doctors, appointments, etc.)

Server: Apache or Nginx (using XAMPP or LAMP stack)

Benefits of Using MongoDB:
Flexible schema design for managing various types of data (e.g., appointments, users, schedules).

High performance and scalability.

Easier to model nested structures like patient history or doctor availability.
